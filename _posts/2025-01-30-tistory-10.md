<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>논문 제목: Improving&nbsp;Language&nbsp;Understandingby&nbsp;Generative&nbsp;Pre-Training&nbsp;(GPT-1)</li>
<li>논문 저자: Alec Radford, Karthik Narasimhan, Tim Salimans, Ilya Sutskever(OpenAI)</li>
<li>논문 출처: <a href="https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf">https://cdn.openai.com/research-covers/language-unsupervised/language_understanding_paper.pdf</a></li>
</ul>
<h2 data-ke-size="size26">Abstract</h2>
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>자연어 이해에서 발생하는 다양한 과제들-텍스트 함의(textual entailment), 질문 응답(question answering), 의미 유사성 평가(semantic similarity assessment), 문서 분류(document classification) 등-의 성능 향상을 위해 <b>Generative Pre-Training(GPT)</b> 접근 방식을 제안</li>
<li>라벨링 되지 않은 대규모 텍스트 코퍼스는 풍부하지만, discriminatively trained 모델이 적절한 성능을 발휘하기 어려움
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>discriminatively trained model: 주어진 데이터에서 입력과 출력 간의 관계를 <b>직접 학습</b>하는 모델</li>
</ul>
</li>
<li>GPT는 대규모 비지도 텍스트 코퍼스에서 생성적으로 사전 학습을 수행(generative pre-training)한 후, 각 과제에 맞춘(task-aware input transformation) 소규모 지도 학습(discriminative fine-tuning)을 통해 모델을 미세 조정
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>모델 아키텍쳐에 최소한의 변화를 주며 효과적인 전이 학습(transfer) 가능</li>
<li>전이 학습: 이미 학습된 모델이 다른 관련된 작업에 학습한 지식을 전이하여 사용하는 기법</li>
<li>많은 기존 모델은 특정 작업에 맞게 아키텍처를 변경하거나 복잡한 추가 모듈을 설계</li>
<li>GPT는 <b>일관된 모델 구조</b>를 유지하며, 작업별로 입력 형식만 변환(task-aware input transformation)하여 다양한 작업에 적응</li>
</ul>
</li>
<li>이 모델은 특정 과제에 특화된 기존 아키텍처를 뛰어넘어 12개의 실험 과제 중 9개에서 최신 성능(State-of-the-Art)을 달성
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>8.9% on commonsense reasoning (Stories Cloze Test), 5.7% on question answering (RACE), and 1.5% on textual entailment (MultiNLI)</li>
</ul>
</li>
</ul>

<h2 data-ke-size="size26">1. Introduction</h2>
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>기존 방법의 한계
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>수동으로 라벨링 된 데이터 필요</li>
<li>비지도로 좋은 표현 학습하면 비용 절감, 성능 향상</li>
<li>지금까지 사전 학습된 단어 임베딩을 사용한 경우는 있었으나, word-level information 이상의 정보를 활용하는 것은 어려웠음
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>어떤 유형의 최적화 목표(optimization objective)가 효과적인지 파악이 어려움</li>
<li>학습된 표현을 target task로 옮기는 효과적인 방법에 대한 동의 부재</li>
</ul>
</li>
</ul>
</li>
<li>GPT
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>개념
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>semi-supervised apporach for language understanding task</li>
<li>비지도 사전학습(pre-training) + 지도 미세조정 (fine-tuning)</li>
</ul>
</li>
<li>훈련 절차: 2단계
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>비지도 사전학습(unsupervised pre-training): 언어 모델링 목표를 사용하여, 라벨링되지 않은 데이터에 초기 파라미터 학습</li>
<li>지도 미세 조정(supervised fine-tuning): 지도 목표를 사용하여 파라미터를 목표 task에 맞게 조정</li>
</ul>
</li>
<li>모델 아키텍처: transformer 사용
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>텍스트의 장거리 의존성(long-term dependency)*을 처리하기 위한 구조화된 메모리를 제공하므로 다양한 작업에서 강력한 transfer 성능 보임
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>장거리 의존성(long-term dependency)
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>텍스트가 멀리 떨어져있을 때도 맥락하는 파악하는 능력</li>
</ul>
</li>
</ul>
</li>
<li>transfer 중에는 task-specific input adaptation을 사용하여 구조화된 텍스트 입력을 하나의 연속적인 토큰 시퀀스로 처리</li>
<li>아키텍처를 최소한으로 변경하며 효과적인 fine-tuning 가능</li>
</ul>
</li>
<li>평가 방식
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>4가지 업무에 대해 평가: 자연어 추론, 질문 답변, 의미적 유사성, 텍스트 분류</li>
<li>8.9% on commonsense reasoning 상식추론 (Stories Cloze Test), 5.7% on question answering 질문 답변 (RACE), and 1.5% on textual entailment 텍스트 함의 (MultiNLI)</li>
</ul>
</li>
</ul>
</li>
</ul>

<h3 data-ke-size="size23">3.1 Unsupervised pre-training</h3>
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li><b>비지도 사전 학습(Unsupervised Pre-Training)</b>: 대규모 텍스트 코퍼스에서 대용량 언어 모델 학습</li>

<li>k = context window(언어 모델에서 현재 단어를 예측하기 위해 참조하는 이전 단어들의 범위)</li>

<li>input: context token으로 이루어진 시퀀스 &rarr; 임베딩 벡터로 변환되어 모델에 입력</li>
<li>multi-headed self attention
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>Self-Attention: 입력 시퀀스의 각 토큰이 다른 모든 토큰과 상호작용하여 중요도를 계산</li>
<li>Multi-Headed: 여러 개의 Attention 연산(Head)을 병렬로 수행해 다양한 관계를 동시에 학습 - 서로 다른 문맥적 특징을 학습하는 데 도움</li>
<li>토큰 임베딩 벡터 변환 &rarr; attention score 계산 및 정규화 &rarr; 여러 head에서 병렬로 수행한 후 결과 결합</li>
</ul>
</li>
<li>feedforward layer: Self-Attention의 출력은 위치별(position-wise)로 독립적인 Fully Connected Layer에 전달
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>cf) fully connected layer: 노드가 이전 층의 모든 노드와 연결된 인공신경망의 구성 요소. , 모든 입력이 각 출력에 영향을 미치며, 이를 통해 입력 간의 복잡한 관계를 학습.</li>
<li>cf) feedforward layer: Self-Attention 이후 등장하는 두 개의 Fully Connected Layer로 구성된 서브 네트워크
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>첫 번째 Fully Connected Layer는 입력을 고차원 공간으로 확장</li>
<li>두 번째 Fully Connected Layer는 이를 다시 원래의 차원으로 축소</li>
<li>이 과정은 비선형 활성화 함수 (e.g., ReLU, GELU)를 포함하며, 각 토큰의 표현을 독립적으로 처리</li>
</ul>
</li>
</ul>
</li>
<li>output distribution: Feedforward Layer를 거친 결과는 각 토큰에 대해 <b>다음 토큰의 확률 분포</b>로 변환되며, 이 확률이 softmax로 계산됨
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>cf) softmax 함수: 입력 값을 확률 분포로 변환하는 수학적 함수. 각 입력 값이 특정 클래스에 속할 확률을 계산하도록 돕는 역할.
<ul style="list-style-type: disc;" data-ke-list-type="disc">

<h3 data-ke-size="size23">3.3 Task-specific input transformations(작업별 입력 변환)</h3>
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>classification: 직접 model fine-tune 가능</li>
<li>entailment: have structured inputs. 전체 p와 가설 h 토큰 시퀀스를 연결하고 그 사이에 구분 기호 토큰 $를 넣음.</li>
<li>&harr; 사전학습된 모델은 연속된 텍스트 시퀀스에 대해 학습되었으므로 수정 필요</li>
<li>similarity: 비교 대상인 두 문장의 고유한 순서가 없으므로, 입력 시퀀스를 두 가지 가능한 문장 순서 모두 포함하도록 수정하고, 각각을 독립적으로 처리하여 두 개의 시퀀스 표현 생성</li>
<li>Q&amp;A: 문맥 문서 z, 질문 q, 가능한답변 {a} 집합이 주어짐. 문맥과 질문을 각각 가능한 답변과 연결하고, 그 사이에 구분 기호 토큰 추가</li>
<li>이전 연구: 전이된 표현(transferred representation)을 기반으로 작업별(task-specific) 아키텍처 학습</li>
<li>&harr; 해당 연구; traversal style : 구조화된 입력을 사전학습 된 모델이 처리할 수 있는 ordered sequence로 변환, 아키텍처 변경 피할 수 있음</li>
</ul>

<li>비언어모델 학습: Books Corpus Dataset
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>모험, 판타지, 로맨스 등 다양 한 장르의 미출간 도서 7,000여 권이 포함</li>
<li>연속된 긴 텍스트가 포함되어 있어 생성 모델이 장거리 정보를 조건으로 학습</li>
<li>alternative dataset: 1B Word Benchmark (비슷한 크기)</li>
</ul>
</li>
<li>모델 사양
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>Transformer 아키텍처:
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>12층(layer) 디코더 전용 Transformer 사용</li>
<li>각 층은 768 차원 상태와 12개의 self-attention heads로 구성</li>
</ul>
</li>
<li>학습 설정:
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>학습률: 2.5e-4로 설정, 초기에는 선형적으로 증가 후 코사인 감소 스케줄 사용</li>
<li>100회 반복 학습(epoch): 각 배치(batch)는 64개의 512개 토큰 시퀀스로 구성</li>
</ul>
</li>
<li>규제와 정규화:
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>드롭아웃(dropout) 비율: 0.1</li>
<li>40,000개 서브워드 단위(BPE, bytepair encoding) 어휘 사용
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>cf) BPE: 가장 많이 등장하는 문자 쌍(pair)을 반복적으로 병합하면서 단어를 작은 조각으로 나누는 방식</li>
</ul>
</li>
<li>L2 정규화: 가중치에 0.01 적용
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>cf) L2: 신경망을 훈련할 때 가중치(weight)가 너무 커지면 과적합(overfitting)이 발생할 가능성이 커지므로, 이를 방지하기 위해 penalty를 부여하는 것</li>
</ul>
</li>
<li>활성화 함수: GELU(Gaussian Error Linear Unit) 사용
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>cf) 활성화 함수: 신경망에서 <b>입력값을 비선형적으로 변환</b>해서 모델이 복잡한 패턴을 학습할 수 있도록 도와주는 함수</li>
<li>cf) ReLU와의 비교: GELU는 더 부드러운 활성화 함수
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>ReLU는 x가 0보다 크면 그대로 출력, 0보다 작으면 0 출력 &rarr; 비연속적인 변화 발생!</li>
<li>GELU는 입력값을 확률적으로 조정해서 더 부드러운 활성화를 수행!</li>
</ul>
</li>
</ul>
</li>
</ul>
</li>
<li>초기화 및 데이터 전처리
<ul style="list-style-type: disc;" data-ke-list-type="disc">
<li>초기 가중치 분포: N(0,0.02)</li>
<li>BooksCorpus 데이터셋에서 텍스트를 정리, 표준화, 토큰화(spaCy 사용)</li>
</ul>
</li>
</ul>
</li>
