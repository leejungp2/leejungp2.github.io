<h3>How did we get here?: Techniques for training LLMs</h3>
<p><strong>Transformer Achitecture</strong></p>
<ul>
<li>decoder only<ul>
<li>기존에 enco-deco 구조는 다른 매개변수를 통해 작업을 이해하는 방식을 학습해야 하므로 중복적</li>
<li>오늘날 decoder-only architecture에만 관심있음</li>
</ul>
</li>
<li>pre-layer norm(more stable gradients)<ul>
<li>original transformer에서 pre-layer norm은 residual connection 뒤에 있음 → post-layer norm</li>
<li>현재는 pre-layer norm 사용</li>
<li>Gradient 안정성 향상</li>
</ul>
</li>
<li>rotary position embedding(faster convergence)<ul>
<li>논문이 아닌, 중국 블로그에서 게재됨</li>
<li>very efficient</li>
</ul>
</li>
<li>group query attention(save inference memory)<ul>
<li>메모리 사용을 줄이고 효율성을 높임</li>
</ul>
</li>
<li>GLU variants(better w.r.t. same number of params)<ul>
<li>replace MLP, 동일한 파라미터 수로 더 나은 성능 제공</li>
</ul>
</li>
<li>Mixture-of-Expert(the same FLOPs, more parameters, better performance)<ul>
<li>동일한 계산량(FLOPs)으로 더 많은 파라미터를 활용하여 성능 개선</li>
</ul>
</li>
</ul>
